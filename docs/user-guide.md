# NyaEH 使用指南

[返回首页](../README.md) · [开发指南](development.md)

## 漫画卡片

普通卡片将封面、标题、元信息和阅读状态放在同一块圆角底板内。默认卡宽为 144 点，封面宽高比为 4∶5。搜索会记住卡宽，首页展示卡根据窗口自动排布。

右键或 Control 点按普通卡片，可以查看详情、阅读、收藏、标记已读或未读、复制完整标题或在 Finder 中定位文件。有来源网址时可打开网页。有系列或版本组时，菜单还可以查看所属系列、直接管理该系列或版本组。阅读和阅读状态对应卡面版本，收藏在本版本组内同步。卡片右上角的爱心用于切换收藏。可以在「设置 → 通用 → 漫画卡片」逐项隐藏副信息。

将指针停在叠放的元信息行上，各版小卡会从该行依次展开；聚焦卡片后按 V，或聚焦元信息行后按 Return，也可展开。方向键选择，Esc 收起。点击其中一个版本或按 Return 确认，会将它保存为本卷的主版本，成功后会显示提示。右下角的阅读按钮从卡面版本上次的位置继续阅读，进度条上的 P14 表示当前读到第 14 页。分组卡的评分取可见版本中的最高分，悬停可查看来源。搜索单本模式和首页「最近添加」显示每个条目自己的元信息和评分。


## 封面隐私

打开「设置 → 通用 → 封面隐私」可选择模糊或完全遮盖漫画封面。默认关闭。模糊强度从 1 到 100，默认 50。设置里的大小样图可用来比较强度和练习悬停揭示。

默认停留 1 秒后显示指针下的封面。延时支持小数，0 表示立即显示，选择「永不解除」可持续保护。模糊封面在到时后逐渐变清晰，开启系统「减少动态效果」时直接显示。指针移出时封面逐渐恢复模糊；切书或窗口失去焦点时立即恢复保护。首页小封面和大图分别计时。

保护范围为首页、搜索、作品与角色专题，可分别覆盖保护方式、强度或延时。搜索系列成员浮窗沿用搜索设置。书籍详情、系列详情、管理页及其他页面直接显示封面。此功能仅处理漫画封面，详情内页预览、阅读器内容和专题自定义插画照常显示。

## NyaEH 能做什么

### 本地书库

- 扫描本地 `.zip` / `.cbz` 文件，记录路径、大小、修改时间、页数、代表 SHA1 hash 和文件状态。
- 自动生成封面缓存，列表和详情页优先读取缓存，减少重复解压 archive。
- 识别 missing、broken、unscanned、correct 等状态；源文件缺失会显示为状态，不会让整个书库不可用。
- 详情页可对单本重扫封面和文件状态。

### 元数据

- 通过代表图 SHA1 在 E-Hentai / ExHentai 搜索，并保存标题、日文标题、评分、页数、发布时间、分类、URL 和 tags。
- 支持单本获取、通过 gallery URL 直接获取、清空元数据、手动编辑元数据。
- 支持批量获取元数据，并可在设置中配置请求间隔、重试次数和数量上限。
- 遇到访问受限、认证失败或连续瞬时错误时，批量任务会暂停，避免持续请求远端站点。

### 浏览与搜索

- 首页展示器按「继续阅读」「最近观看」「今日推荐」各取前五本，每六秒在当前分类内切换。主推右下角常驻三个分类和当前分类的一排小封面。指针在分类名上短暂停留即可切组，移入小封面即可预览，左右方向键切书，上下方向键换分类，Esc 回到主推封面。选书时轮播暂停。主推与我的收藏共用作品资料布局，按分类逐行显示标签，收藏标签在各分类中优先显示。点按或悬停「+N」可查看该类全部标签。点大封面或书名查看详情，点阅读按钮可从当前版本保存的位置打开。常规窗口首屏可完整展示主推与我的收藏两张卡。收藏卡左侧展示大封面，右下角可横向滑动一排小封面，悬停或键盘聚焦即可选书。先按最近观看、再按上传时间从新到旧排列，时间相同时按书名字母顺序排列。最多显示十本，超过十本时点第十个虚化封面进入收藏管理。最近添加显示最近三个入库日，每天最多预览七本，有更早入库日时第三个日期后会出现渐隐细线。该日超过七本时，末个封面虚化，点击它会进入全库逐本搜索，并按入库时间从新到旧排列。
- 主窗口会记住上次调整的窗口大小和侧栏宽度。点击侧栏的「类别」或「管理」整行可展开或折叠各自的子项，点击「系列」打开系列管理。
- 首页与搜索页的卡片大小滑杆使用相同的浮动玻璃面板，两页各自记住卡片大小。
- Search 是统一书库入口；空查询展示全部非隐藏书籍，并支持收藏、继续阅读、未读、已完成、缺少元数据、损坏、缺失和隐藏范围。
- Search 支持 SQLite 分页、稳定排序、卡片/紧凑列表/详细列表、多选批量整理、条目预览和保存搜索；系列成员与非主版本同样可被搜索，并分别折叠为系列结果或主版本结果。
- Search 卡片的封面按原比例显示，收藏爱心位于封面右上角。按住 ⌘ 点按封面或标题可逐项选择，系列成员浮窗也支持这一操作。右键或 Control 点按打开菜单，只有「选择／取消选择」会改变选区。选中状态显示在卡片外缘。点击系列卡片会原位弹出成员封面网格，复用搜索页的卡片大小设置。浮窗宽度优先容纳四列，窄窗口自动减少列数，内容超出时在浮窗内滚动。Tab／Shift+Tab 切换焦点、Return 打开成员、Esc 或点击外部关闭。从单本详情返回会恢复浮窗、滚动位置与成员焦点；改变搜索条件、分页或布局会清除恢复记录。完整系列页可通过“系列详情”打开。
- 搜索工具栏的「显示系列成员」开启时，三种视图均按单本漫画匹配、排序、计数和分页。关闭时系列作为一项结果。紧凑条目可点击系列箭头纵向展开。扩展条目始终横排显示系列封面，支持左右翻页和按需加载。系列与单本默认等高，单本可点击「全部标签」按分类展开完整标签。系列详情有独立按钮，点击成员打开详情。条目与扩展条目的收藏按钮使用爱心，右键或 Control 点击切换批量选中，选中状态显示在条目外缘。
- Search 支持选择封面图片或将图片直接拖入页面进行按图搜索；查询图片不会保存，结果按封面向量距离排序。
- 强搜索支持标题搜索、正则标题搜索、标签包含/排除、OR、精确匹配、引号、多词标签和后缀通配符；范围可与这些条件组合。
- 标签分类页按 Artist、Group、Parody、Character、Female、Male、Mixed、Location、Other 等 namespace 浏览本地标签。
- 创作者、作品与角色、标签分类页在窗口顶栏切换子页面、排序和搜索当前子页面的标签；搜索匹配显示名与原名，并在切换子页面时清空。标签页先显示“全部”，选中“按分类”后才出现分类菜单；排序方式、方向和全局操作各自成组，窄窗口的排序收进菜单，底部分页栏保持可见。
- 点按作品页书架上的角色名可进入角色专题，也可从角色专题的作品分区返回作品专题；返回路径只保留最近两张专题页。角色未设置背景时，会继承首个有背景的关联作品。
- 向下滚动时，作品介绍卡会逐渐收起，保留作品标识、角色数、本数和搜索入口。滚回顶部可展开介绍，点按作品前景图可临时切换为标题。
- 在角色条上快速划过只会轻轻抬起经过的小卡。停稳、点击或用方向键选中角色后，原来的大卡缩回原位，新卡从角色条移到下方。条中的空位表示当前角色，缺少立绘时卡片显示角色名首字。开启系统「减少动态效果」时，卡片在原位淡换。
- 新角色落位后，漫画从右侧滑入。横向浏览书架时，封面可以滑过角色卡背后并进入侧栏下方。普通鼠标的纵向滚轮也可在角色条内横向找人。
- 在角色条右侧打开「待归类」，可给单本漫画补上库内已有的角色标签。一本漫画涉及多部作品时，补标签后仍可能需要在「管理角色归属」中确认关系。单作品漫画提供作品—角色证据；可在作品专题页管理关系，也可从漫画详情的角色标签确认全书库关系。多作品漫画在已知关系排除后仅剩一组作品与角色时，会针对该漫画自动认领并标明依据；自动结果不继续推断，且可撤销。
- 角色专题页为高立绘预留展示空间；窄窗口会将介绍移到立绘上方，透明立绘会在展示时自动收紧空白边缘，原图文件不变。
- 分类列表使用可悬停放大的玻璃卡片：作品 Logo 为横卡，角色立绘为竖卡，创作者和内容标签为紧凑文字卡。作品与角色的透明图片会在显示时收紧留白，直接呈现在页面上；名称、漫画数量和收藏按钮位于下方的圆角玻璃信息区。
- 作品、角色专题页及漫画详情页的背景会延伸至窗口顶栏；顶栏隐藏页面标题，保留返回和操作按钮。
- 可关注常用标签，让它们在标签列表、详情页和搜索建议中更容易被发现。

### 阅读与预览

- 详情页可按需从 `.zip` / `.cbz` 原文件加载漫画页面。
- 独立阅读窗口使用自动隐藏的底部 Liquid Glass 控制卡，隐藏系统红黄绿按钮，并在卡片内保留缩略图开关、显示菜单、居中的翻页区、全屏和关闭操作；默认页码可点击后原位输入跳转，控制卡不重复显示文件名。
- 单页与双页模式可使用鼠标滚轮、触控板横扫、左右点击区和键盘翻页；连续模式保留原生滚动。左侧缩略图以浮动玻璃侧栏按需展示，点击可跳页，双页模式会标记整个跨页范围；侧栏开关与布局、适应方式和缩放一起作为全局阅读器偏好恢复。
- 窗口首次占当前显示器可用区域约 85%，之后通过应用偏好恢复上次尺寸和位置。除页码输入框外，控制卡和缩略图控件不参与键盘焦点导航，避免焦点环干扰阅读快捷键。
- 每本书持久化当前页和完成状态，打开时恢复位置；达到 95% 自动完成，也可手动完成或重置。
- 阅读器只预取当前位置附近页面并释放远端图片；`read_count` 和 `last_read_at` 仍作为最近阅读摘要。
- 阅读窗口只打开并枚举 archive 一次；页面解码在后台执行，缓存按解码后内存成本限制在物理内存的 5%（128–384 MiB）。缩略图通过 ImageIO 最长边 320px 的独立降采样按可见范围加载，并使用约 32 MiB 的独立成本缓存。

### 任务、备份与维护

- 工具栏任务中心集中展示扫描、元数据、导入、标签/角色索引、推荐、封面向量和语义标题索引任务的状态与错误。
- “设置 > 存储与维护”可导出或恢复版本化 `.nyaehbackup` 包，并在恢复前验证 SQLite 完整性和外键。
- 自动备份每日最多一次，保留 7 个日备份和 4 个周备份；恢复、外部导入和修复派生数据前会强制备份。
- 同一漫画的各版本在系列里共用一个位置。升级会在备份后补齐归属明确的旧数据；可在「存储与维护 → 数据健康检查」查看问题。涉及多个系列时，选择目标系列并确认后才会统一归属。
- 备份包含 `NyaEH.sqlite` 和 `TagAssets`，不包含源漫画、封面/翻译/向量缓存或本地凭据文件。
- 数据健康检查覆盖 SQLite、标签、版本标签、组织关系、阅读进度以及孤立的封面、TagAssets 和封面向量；检查与修复分开执行。还会检查无效推荐、缺失主版本、空分组、结构性隐藏状态、导入计数及待恢复的删除操作。

### 合集与版本组

- Collections 用于管理同系列作品；支持手动添加、移除、重命名和成员排序。
- 系列管理页只使用卡片成员视图，保留一键结构化标题排序、拖拽与菜单排序。已确认系列中的普通无编号成员会稳定置顶，其后按数字、中文/罗马数字、Vol/Part/Chapter、上中下及同 family 编号刊物排序；特殊篇、无法可靠解析或冲突的成员稳定置后。
- 开发版可显式启用本机 `NLContextualEmbedding` preprocessing v3 系列推荐，precision-first profile 使用平方 L2 `0.2767` 与 mutual Top-3。模型和索引仍由用户显式下载/建立，默认关闭且不会在导入中自动下载；不可用时自动退回词法规则。v3 会为干净的无编号标题生成向量，并在明确编号系列形成后，以严格词面证据补全缺省第 1 卷。
- 已有系列成员只为“加入系列”提供证据，不会再次组成创建建议；同一本书只保留一个明确胜出的目标，完全同分则不建议。接受创建或加入建议会在同一事务中更新关系、自动排序并使冲突建议失效，普通扫描或推荐刷新不会改动人工顺序。
- Version groups 用于管理同一本书的不同版本，支持主版本、版本标签、组级收藏状态和推荐辅助。
- 系列与版本管理操作会显示“保存中”；可确定的成员、排序和标签变更先在界面显示，写入完成后以数据库记录核对。若保存失败，相关项目恢复到已保存状态并显示错误。
- 系列与版本管理页按“组列表、成员、候选对象”排列；两页左右栏使用居中的一体玻璃切换控件和玻璃搜索框，切换控件选中色跟随应用主题色。新建建议与加入建议分别在对应栏查看。搜索过滤后，有加入建议的系列和版本组稳定置顶，保留当前选中项目。两页组列表的悬停背景与系统选中背景覆盖同一行范围；系列行显示书籍数，版本行不显示成员数，有加入建议时均显示 `sparkles` 徽标。系列页操作与分页使用系统按钮，候选添加使用普通描边样式。两页会各自记住候选栏的展开状态，窄窗口可从工具栏临时打开候选对象。
- 成员列表不分页，数量以低对比度胶囊显示在成员栏左下角，版本页使用“本”作为数量单位；系列名称居中显示，左栏系列行显示对应成员数量。系列成员栏右下角可在确认后删除系列，只解除漫画的系列归属，保留源文件和版本组；版本成员栏右下角可在确认后删除整个版本组，解除版本关系并清除版本标签，保留漫画文件。候选栏保留居中的底部分页控件，两页分别记住每页数量，切换数量后立即从第一页显示并关闭旧悬停预览。
- 系列成员卡片使用大封面的紧凑横向行，行外弱序号随排序更新；卡片右侧留出焦点边距，保留标题复制、封面详情以及悬停或键盘聚焦时同步淡入的移除、拖拽柄和“更多操作”。成员选中用主题色浅底与封面角标表示，区别于系统键盘焦点框。移除与“更多操作”使用相同尺寸的简洁系统外观，移除图标保留红色。普通点击、Command 与 Shift 支持多选，右键或 Control 点击逐项切换选择，拖拽柄可将选中成员按原顺序一起移动。“更多操作”提供详情、Finder 定位、置顶置底、移动系列和移除；已选卡片的整理操作作用于全部已选成员。批量写入继续显示保存状态和逐项失败。成员排序后的候选核对保留现有列表，结果不变时不重建。
- 候选和加入建议卡片悬停 350 毫秒后以浮层显示完整标题与标签，不改变列表位置；鼠标可移入浮层滚动查看，离开卡片与浮层 150 毫秒后关闭。展开按钮仍可将信息固定在卡片内，手动收起后需移开再进入才会恢复悬停预览。列表滚动、切组或窗口失活会关闭预览，滚动后需实际移动鼠标才重新触发；浮层不抢键盘焦点，并适配系统“减少动态效果”。
- 系列名称点击后编辑，按 Return 或失焦自动保存，Escape 放弃。
- 版本成员采用带左右边距的紧凑横向卡片：封面、标题、翻译／彩色／修正／页数状态胶囊和版本标签集中展示；主副版本徽章位于标题行右侧，点击副版本徽章可设为主版本。成员选中用主题色浅底与封面角标表示，区别于系统键盘焦点框，也独立于主副版本状态。更多菜单和移除按钮以同尺寸并排置于卡片右下角，在悬停或键盘聚焦时一起显示并保留隐藏时的布局空间；右键菜单保留直接打开阅读器、查看详情、主版本切换、信息比较和移出版本组。两本组移除一本前会确认整个版本组解散，漫画文件保留，成员移出仍可通过撤销恢复。标签区域悬停或聚焦时显示加号，打开原生浮窗，在同一输入框中过滤快捷／历史标签或输入自定义标签，已添加标签避免重复，标签删除按钮仅在悬停时显示。
- 管理页各内容栏沿用主窗口背景，卡片保留实色底色，玻璃效果用于左右栏的切换控件与搜索框等局部控件；原生工具栏可能已有系统玻璃效果。后续布局稳定后，优先整理工具栏分组，再评估悬停预览、版本标签浮窗和紧凑操作区的 Liquid Glass；密集卡片和标签不逐项叠加玻璃，并需检查浅色／深色、减少透明度、对比度及滚动表现。
- 主窗口、设置和元数据编辑窗口按窗口管理焦点外观：鼠标浏览时隐藏额外的键盘焦点框，系列与版本成员卡片也直接遵循此状态；Tab／Shift + Tab 恢复系统焦点框与原生导航，点击文本输入框保留编辑焦点提示；不改变实际焦点或拦截输入，点击空白也不自动清除成员选中。开启完整键盘控制时同样遵循鼠标与 Tab 的切换；VoiceOver 或切换控制开启时始终保留系统焦点提示。独立阅读器继续使用专用键盘输入规则。
- 版本推荐可选启用封面相似度。开启后，NyaEH 使用 Apple Vision feature print 和 sqlite-vec 缓存封面向量，辅助判断近似版本。
- 搜索页支持选择外部封面图片，在本地封面向量索引中按视觉相似度查找已有作品；查询图片和临时向量不会写入数据库，结果沿用合集/版本组折叠和详情打开流程。
- 推荐只作为缓存建议存在；只有用户接受推荐时才会修改合集或版本组关系。标题解析出的 `ordinalKey` 不写入数据库，排序仍只使用 `library_books.collection_order`，同版本组次版本会同步主版本顺序。

### 标签翻译与专题素材

- 可下载 EhTagTranslation/Database 最新 release 的 `db.text.json`，为本地已知标签提供中文名称、说明和链接。
- 翻译缓存只物化本地书库出现过的标签，不会把完整远端词库全部写入主库。
- 作品和角色列表及专题页支持拖入展示图；专题页也支持拖入背景图。已有的展示图、背景、裁剪和配色配置继续用于专题页，卡片配置窗口已移除。

### 本地网页高亮

- 设置中可开启 Local Gallery Highlight，让 E-Hentai / ExHentai 列表页高亮本地已经存在的 gallery。
- 该功能使用默认关闭的 localhost 只读接口，并配套 Tampermonkey userscript。
- 接口只暴露 gallery gid 列表，不暴露本地路径、标题、hash、tags 或凭据。

### 外部导入

- 可从 `exhentai-manga-manager` 文件夹导入 `metadata.sqlite`、`database.sqlite` 和 `collectionList.json`。
- 导入会先备份当前数据库。
- 只按 SHA1 hash 匹配已经扫描进 NyaEH 的书籍；源库或目标库存在重复 hash 时会保守跳过。

### 智能导入流水线

- “继续处理全部未完成”会固定当前导入收件箱中的书籍 ID，建立可跨启动恢复的批次；分析开始后新扫描到的书进入下一批。
- 元数据按书串行处理，依次尝试手填画廊网址、源压缩包中可选的 `webinfo.txt` 画廊网址、本地 Hash 缓存和远端 Hash 搜索。`webinfo.txt` 缺失或内容无效时继续尝试后续来源；有效网址的 API 获取失败时不改用 Hash 搜索。无结果、无效 Hash/网址或源文件问题只暂缓该书；访问限制、认证失败和连续网络故障会暂停远端队列。
- 批次到达元数据屏障后，只执行一次版本分析。分析从整个有效书库取候选，但新增推荐必须涉及当前批次的 focus 书籍，因此同批版本、旧书和已有版本组都可被发现。
- 用户处理完版本推荐后，NyaEH 重新读取全库和最终主版本，再执行一次系列分析；同批多卷和跨批新增卷都可匹配。
- 导入页始终按原始 `LibraryBook` 记录逐条显示，不折叠系列或版本组，也不隐藏副版本。每条记录保留独立阶段、错误、重试网址、跳过状态和忽略推荐重置入口。
- 导入页以响应式四阶段仪表盘呈现扫描、元数据、版本与系列进度；原始记录收件箱支持标题、日文标题、路径、SHA1 搜索，以及待处理、待审核和需处理状态筛选。
- archive 的代表 SHA1 未改变时重扫会保留元数据；SHA1 改变时会清除不再可信的 gallery 镜像并重新进入导入收件箱，同时保留阅读与人工组织关系。若已有系列或版本关系，需要在重试前明确确认继续保留。
- 外部标签会转换为 NyaEH 的 `namespace:tag` 形式，并重建本地标签索引。

### 偏好设置

- 支持 theme、accent color、language、标题显示模式、阅读器初始加载数量、阅读器悬停预览延迟、书库目录、metadata 站点、网络代理和 ExHentai credentials。
- 设置页还提供标签翻译更新、推荐缓存重建、封面向量维护，以及 CJK 语义模型下载与标题索引维护；备份、恢复、数据库检查与 VACUUM 集中在“存储与维护”。

### 性能与大书库

- 主数据库使用 WAL + GRDB `DatabasePool`，Search 页面结果与 facet 分阶段、可取消地加载。
- Search facet 会按查询语义缓存；分页、排序和布局变化不会重复聚合，正则候选按 512 条分批过滤。
- 扫描最多并发检查 3 个 archive，按路径顺序确定性提交，并用临时路径表完成缺失检测。
- 封面按 128/256/512 像素档位后台降采样，同一路径并发请求会合并，解码缓存上限为 192 MiB。

## 典型使用流程

1. 打开 Settings，选择你的本地书库目录。
2. 回到主窗口扫描书库，NyaEH 会记录 archive 信息并生成封面缓存。
3. 配置 E-Hentai / ExHentai 站点和凭据，然后为单本或批量书籍获取 metadata。
4. 使用首页、Search 或标签分类浏览收藏；深度筛选和批量整理统一在 Search 完成。
5. 在详情页阅读、编辑 metadata、查看标签解释或打开相关书籍。
6. 用 Collections 整理系列作品，用 Version groups 管理同一本书的不同版本。
7. 按需更新标签翻译、重建推荐缓存或维护封面向量缓存。

## 数据与隐私

### 原始文件

- 原始 `.zip` / `.cbz` 文件保留在你的源目录。
- 普通管理操作只更新数据库记录，不会复制、移动或重写 archive。
- 详情页“移到废纸篓”需要输入确认码：先移动源文件，再事务化删除书库记录；无法访问或移动文件时保留书库记录，不会回退为永久删除。
- 删除会同步使相关推荐失效、补选主版本、解散只剩一本的版本组、移除空系列并更新导入计数。最后一条待审推荐消失后，未手动暂停的审核流程继续推进。
- 文件已移走但书库清理失败时，下次启动会重试已确认的数据库清理；移动结果不明确时需在详情页检查后重试。缓存清理失败可通过“数据健康检查 / 修复派生数据”重试。
- 首次升级前会备份数据库并修复历史残留，包括清理所有空版本组和空系列（含手动创建的空组）。历史修复不移动源漫画；旧版已丢失记录但遗留的文件不会被自动删除。
- 沙盒版 NyaEH 会通过安全书签访问你选择的书库目录；扫描、封面生成和阅读预览都会复用该授权。

### 应用数据位置

正式版数据保存在：

```text
~/Library/Application Support/NyaEH/
```

如果旧的 `~/Library/Application Support/NyaEH/` 存在，且新的 NyaEH 数据目录还不存在，应用会在首次启动时迁移旧目录。

通过开发脚本启动时，数据会写入仓库内的开发目录，避免污染正式数据：

```text
.nyaeh-dev/Application Support/NyaEH/
```

开发目录通常包含：

- SQLite 主库 `NyaEH.sqlite`
- 封面缓存
- 可重建的 `CoverVectors.sqlite`
- 可重建的 `SemanticTitleVectors.sqlite`（仅在用户启用本机语义系列推荐后建立）
- 标签翻译 release JSON 缓存
- 开发环境专用明文凭据
- 自动备份目录 `Backups/`
- 阅读器调试文件 `.nyaeh-dev/comic/comictest.zip`

`.nyaeh-dev/` 已被 Git 忽略。

本机已有兼容的书库和 preprocessing-v3 语义索引时，可显式运行
`script/semantic_series_verify.sh` 输出语义系列校准指标。该校准不会下载模型或修改推荐配置。

### 凭据

正式版的四项 E-Hentai / ExHentai Cookie 通过 `CredentialStore` 保存在 `~/Library/Application Support/NyaEH/Credentials/credentials.json`。目录权限为 `0700`，文件权限为 `0600`，写入采用原子替换；保存失败会在“账户”设置中显示错误。旧 Keychain 条目不会被读取或迁移。公开版更新使用匿名请求，不使用或清除私有版的更新令牌。凭据文件不进入 `.nyaehbackup` 或 Git 仓库。

开发脚本会设置：

```text
NYAEH_CREDENTIAL_STORE=developmentPlaintext
NYAEH_USER_DEFAULTS_SUITE=NyaEH.Development
NYAEH_DEVELOPMENT_COMIC_PATH=<仓库绝对路径>/.nyaeh-dev/comic/comictest.zip
```

因此开发环境凭据会保存为明文 JSON：

```text
.nyaeh-dev/Application Support/NyaEH/Credentials/development-credentials.json
```

开发版与 QA 版各用独立的数据目录，不会读取正式版凭据。

`NyaEHDevRunner` 还会在侧栏显示“调试”页面。将测试漫画放到
`.nyaeh-dev/comic/comictest.zip` 后，可从该页面直接打开阅读器；此操作不会扫描书库、
创建书籍记录或保存阅读进度。正式 NyaEH Xcode 壳不传入开发配置，因此不会显示该入口。

在「调试 → 漫画卡片 → 样卡对照台」可并排比较同一本书的旧版与新版整张书卡，也可单独查看其中一款。默认卡宽为 144 点，可切换卡宽及三种背景，检查长短标题、版本叠卡和阅读进度。收藏、主版本和阅读进度只在本次对照台中生效；返回后再进入会恢复初始样本。阅读按钮使用同一份测试漫画。

打开「调试 → 首页书架预览」可比较旧版书架与首页实际使用的收藏、最近添加大卡。固定样本涵盖同日大量入库、不同版本及单本收藏。预览中的书籍操作只影响本次会话。「在搜索中查看全部」进入当前开发书库的真实搜索结果。

## 本地网页高亮

1. 打开 Settings > Network。
2. 启用 Local Gallery Highlight，并按需调整端口。
3. 点击 Copy Userscript，把脚本安装到 Tampermonkey。
4. 打开 E-Hentai / ExHentai 列表页，脚本会读取本地只读接口并高亮已存在的 gallery。

默认接口为：

```text
GET http://127.0.0.1:23786/api/highlight/v1/galleries
```

响应只包含最小 gallery 身份信息：

```json
{
  "app": "NyaEH",
  "revision": "sha256-of-sorted-gids",
  "gids": ["12345", "67890"]
}
```

## 强搜索语法

侧边栏 Search 页面提供固定在结果区上方的搜索面板和可折叠标签筛选面板。保存搜索、文字搜索和封面搜索位于搜索框同一行；紧凑书库范围菜单、单层玻璃模式双选与可横向滚动的已选标签位于下一行。窗口工具栏依次分为排序（排序方式与方向）、显示（布局、固定页头与合集成员）、工具（搜索语法、任务中心与设置）三个独立胶囊；图标使用无彩色外观，模式双选的选中色跟随应用主题色。窄窗口通过具名操作组保留系统溢出菜单。

- 不输入关键词时直接展示全部非隐藏书籍；范围菜单按书库、阅读进度和需处理分类，可切换收藏、阅读进度、元数据和文件状态。
- 顶部搜索框支持普通标题搜索和正则标题搜索；输入只更新草稿，按 Return 或点击搜索按钮才执行搜索。
- 标签建议浮在搜索框下方，不改变搜索面板高度；可用鼠标点击或上下键选中，按 Return 插入选中建议，Esc 关闭建议；插入建议后需要再次提交搜索。
- 标签语法示例：`f:tomgirl`、`-f:tomgirl`、`p:"love live"$`、`~f:school_uniform ~m:school_uniform`。
- 广域模式会把已选标签作为并集；精确模式会把已选标签作为交集，并动态更新标签数量。
- 标签面板按 namespace 展示本地标签，Tag Pill 可在包含、排除、未选中三种状态间切换。
- 开启标签翻译后，输入建议和标签显示会使用本地 `tag_translations` 缓存，例如输入中文翻译词可联想到对应原始标签。
- 紧凑条目与折叠系列等高。鼠标悬停或键盘聚焦条目时，右侧固定区显示封面和摘要。窄窗口可按空格或点击行内预览按钮打开浮窗。点击单本标题或按 Return 打开详情。右键或 Control 点击切换批量选中，可收藏、隐藏、重扫、获取元数据或加入系列或版本组。

旧 `.library` 路由和 `LibraryShelfView` 仅为内部程序化兼容入口，已标记 deprecated，不会出现在侧边栏、菜单或用户流程中。

## 从旧版升级

从 1.4.3 或更早版本升级时，新版会将旧数据库复制成经过完整性检查的 `NyaEH.sqlite`，并保留旧库。新版继续读取旧备份，也会保留已有偏好、书库文件夹授权和凭据文件。请不要并行使用新旧两版，也不要用旧版打开新版创建的备份。旧版如果无法检查更新，可从新仓库的 Release 手动安装一次。
